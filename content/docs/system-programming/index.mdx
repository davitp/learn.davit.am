Welcome to **Systems Programming**. This course is about how programs interact directly with
the operating system through the kernel API. You'll move from exploring the Linux environment
and the command line, through files, processes, and threads, to synchronization, inter-process
communication, and network programming — writing real C/C++ that talks to the kernel at every
step.

## Start here

<Callout title="Your first steps">
1. Read the first topic — [Introduction to Unix and Linux](/system-programming/topics/intro).
2. Set up your environment by completing
   [ENV-1: Setup GNU/Linux Environment](/system-programming/homeworks/environment/environment-setup).
3. When you start compiling code, keep the
   [Compilation guide](/system-programming/guides/compilation) handy.
</Callout>

From there, work through the [Topics](/system-programming/topics) in order — each one links to
the related samples and homeworks as you go.
